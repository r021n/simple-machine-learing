# Simple Machine Learning Projects

A collection of simple machine learning projects for learning purposes. This repository contains various ML projects covering regression, classification, and neural network implementations using Python and Jupyter Notebook.

## Projects

### Regular Machine Learning

- **Breast Cancer (Wisconsin)** - Classification
- **California Home Price Prediction** - Regression
- **Customer Churn Prediction** - Classification
- **Diabetes Linear Regression** - Regression
- **Handwritten Digit Classification (MNIST)** - Classification
- **Heart Disease Prediction** - Classification
- **Klasifikasi Bunga Iris** - Classification
- **Simple Movie Recommendation System** - Recommendation
- **Spam vs Ham Email Classification** - Classification
- **Titanic Survival Prediction** - Classification
- **Wine Quality Prediction** - Regression

### Neural Network

- **Fashion Classification NN** - Image Classification
- **Handwritten Digit Classification (MNIST)** - Classification

## Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/simple-machine-learing.git
   cd simple-machine-learing
   ```

2. Install required packages:

   ```bash
   pip install numpy pandas matplotlib scikit-learn tensorflow jupyter
   ```

3. Run Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

4. Open any `.ipynb` file to explore the projects.
